# ImageGen constellation art direction

Generated 2026-10-20 with the built-in ImageGen tool. All four original transparent PNG outputs are retained unchanged. The browser displays the original transparent PNGs directly behind the alpha cloud layer. An earlier traced star atlas was rejected by the owner and is no longer loaded; `../constellation-art.js` is retained only as superseded source.

## Shared final prompt

Use case: stylized-concept. Asset type: production constellation artwork reference for a transparent animated website sky. Create a very wide panoramic celestial star drawing spanning the entire upper sky, on genuinely transparent background. Realistic astronomical aesthetic: irregular discrete blue-white stars of different magnitudes joined by extremely fine dim straight constellation lines, subtle restrained star glow, no continuous neon outline. Sparse peripheral stars across the full width. Central subject readable through star placement, not a filled illustration. Leave generous breathing space around it and keep bottom quarter almost empty for foreground clouds. Cool near-white with barely icy blue, no text, no labels, no panel, no frame, no landscape, no clouds, no UI. The result will be carefully translated into interactive star geometry behind existing clouds.
