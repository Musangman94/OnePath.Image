# OnePath.Image frontend

The canonical application entry is [`../index.html`](../index.html) from this folder, or [`index.html`](../index.html) when browsing the repository's `OnePath.Image/` directory. It contains the Home scene and the Workspace and Company preview in one document. Use the C control to move between spaces.

The earlier `os-preview-v2` folder is retired as an application source. Its `index.html` redirects to the canonical entry; its screenshots remain as historical discussion artifacts and are not approved design evidence.

The Workspace, Company details, and sample task content are presentation-only. They do not connect to an agent service or backend.
